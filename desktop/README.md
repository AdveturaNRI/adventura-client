# Adventura Desktop (Electron)

Оболочка вокруг `https://adventu.ru`: tray, FreeDesktop-уведомления, call PiP, автообновление.

## Windows

```powershell
cd desktop
npm ci
npm run dist:win
```

Установщик находится в `desktop/release/Adventura-Setup-0.6.12.exe`. Приложение загружает сайт `https://adventu.ru`, поэтому для его работы нужно подключение к интернету. При закрытии окна оно продолжает работать в трее; выйти можно через меню значка. В меню значка в трее есть пункт «Тест уведомления». Уведомления появляются справа внизу, входящий звонок — по центру экрана, текущий звонок — в плавающем окне поверх других окон.

## Установка

```bash
sudo dpkg -i /home/moskowpsix/project_vs/adventura-client/desktop/release/Adventura-0.5.0.deb
```

Или:

```bash
curl -fsSL https://raw.githubusercontent.com/AdveturaNRI/adventura-client/main/desktop/install-linux.sh | bash
```

После установки: меню → **Adventura**, бинарь `adventura`.

## Call PiP (поверх окон)

С **0.5.0** shell сам детектит звонок на `adventu.ru` (DOM: «Завершить звонок» / «Принять») и поднимает always-on-top окно — **деплой веба не обязателен**.

- Перетаскивание за шапку / медиа
- `–` свернуть в компактную полоску, `+` развернуть
- Мик / Открыть / Сброс

**Fullscreen игры:** exclusive fullscreen (Vulkan/OpenGL) часто перекрывает любое always-on-top. Windowed / borderless fullscreen — обычно PiP остаётся. Это ограничение Linux/X11/Wayland, не бага приложения.

## Автообновление

Windows NSIS и Linux AppImage проверяют `https://api.adventu.ru/api/desktop-updates` при запуске и каждые четыре часа. После согласия пользователя обновление скачивается, проверяется по SHA-512 и устанавливается с перезапуском приложения. `.deb` автоматически не обновляется; для автоматических обновлений в Linux используйте AppImage. Для тестирования сервера можно задать `ADVENTURA_UPDATE_URL`.

Для выпуска увеличьте версию в `package.json` и `package-lock.json` и соберите Windows (`npm run dist:win`) или Linux (`npm run dist:linux`). В админке API раздел **«Версии приложения»** доступен суперадминистратору. Выберите платформу и загрузите установщик с именем `Adventura-Setup-X.Y.Z.exe` или `Adventura-X.Y.Z.AppImage`. Файл загружается непосредственно в S3; сервер вычисляет SHA-512 и сохраняет выпуск. Загрузка ещё не включает его для пользователей.

Выберите загруженную текущую версию и минимально допустимую версию `X.Y.Z`, затем сохраните политику. Чтобы откатить выпуск, выберите ранее загруженную текущую версию и при необходимости уменьшите минимальную. Версии и файлы платформ независимы. Текущая не может быть ниже минимальной. До настройки политики сохраняется совместимость со старым `latest.yml` в S3; старый скрипт публикации изменяет только этот резервный манифест и не переключает настроенную политику.

Оболочка с поддержкой политики проверяет её при запуске и каждые четыре часа. При версии ниже минимума она предлагает только обновление или выход; при откате предлагает установить выбранную старую версию. Последняя полученная политика хранится локально и применяется при недоступности сервера. Если политики ещё ни разу не было получено, при недоступном сервере приложение запускается без этой проверки. Установленные ранее сборки без поддержки политики не умеют принудительное обновление и автоматический откат; для них потребуется переход на новую версию или ручная переустановка. Откат программы не откатывает пользовательские данные.
